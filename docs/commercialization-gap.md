# Cinefoundry 商业化差距评估与改进方案（2026-10-17）

**目标**：客户说一句话（可附产品照），无人值守地交付一支**按全球顶级广告片标准制作**的成片——画面达到中国一线广告和好莱坞商业片的质感，声音达到电视广告播音和代言人配音的水准，文案合规，可修改、可批量、可计费。

**默认规格**：16:9 横版、原生 1080p（1920×1080）、24 fps；分辨率做成可扩展档位，为 2K / 4K / 6K 交付留好接口。竖版和方形是可选输出，不再是默认。

评估依据：51 个历史项目的运行记录（`projects/*/reports/run.jsonl`）、dsh-ad-demo 工作区 4 个品类的实测、10 月 17 日的 1080p 实测，以及 harness 代码和 10 个 Skill 的逐行审阅。

---

## 一、总体判断

**技术链路已打通，离“能收费的顶级广告片”还差三步：画质与声音的制作标准、无人值守的稳定性、产品外壳。**

“一句话 → 合规成片”在一台 DGX Spark 上本地跑通，这是最难、也最有壁垒的部分。但现在的成片是“没有出错的 AI 视频”，还不是“导演拍的广告片”：
- **流程只在防守**：代码和 Skill 的规则几乎都在避免模型出错（不画字、不画屏幕、手最多一次），没有规定什么是好镜头、好布光、好剪辑、好声音。
- **画质被管线压低**：标称 1080p，实际是 704×1280 的生成画面，中间片段只有 0.63 Mbps。
- **声音是“念出来的”**：一个通用音色、每句话独立合成、没有音效、没有响度标准。

| 维度 | 现状 | 顶级广告标准 | 差距 |
|---|---|---|---|
| 画质 | 704×1280 生成（LTX 先在 352×640 采样再放大），中间片段 0.63 Mbps，最后拉伸到 1080p | 原生 1080p 起步，中间素材近无损，可上 4K | **大**（10/17 已开始修） |
| 导演语言 | 3 个 5 秒镜头，结构固定；镜头设计只有“避坑”规则 | 有视觉概念、镜头节奏、布光方案、构图留白、镜头间光线和色彩连贯 | **大** |
| 剪辑 | 每个镜头之间都用 0.4 秒叠化 | 以硬切为主，按动作剪；只在情绪转换处溶解 | 大 |
| 调色 | 所有品类一套调色（青橙 + 锐化 + 颗粒 + 暗角） | 按品类和概念定调色方案，镜头间统一 | 中 |
| 配音 | 6 个设计音色、逐句克隆，语气平 | 按品类选角；播音腔贴近电视广告主播或代言人，有重音、气口和情绪 | **大** |
| 音效 | 无 | 环境声 + 动作音效（开罐、倒水、按键）+ 转场声，与画面同步 | **大** |
| 混音 | 配乐压低垫在配音下面，无响度标准 | 网络投放 -16 LUFS / 电视 -24 LKFS，真峰值 -1 dBTP | 中 |
| 字幕与标题 | 每拍一个标题 + 全文字幕，固定位置 | 字幕时间轴与配音逐句对齐；标题排版有层级、有留白、不压主体 | 中 |
| 成功率 | 51 个项目出片 39 个（76%）；6 个卡在分镜 | 无人值守 ≥ 95% | **大** |
| 质检 | 只拦错误；261 次只过 103 次（39%）；13 次没出结论被判失败 | 同时评审美（布光、构图、质感、AI 感）；没出结论应重试 | 大 |
| 速度 | 中位数 35 分钟一支；1080p 后每段约 4 分钟 | 夜间批量排队；单支 30 分钟内可接受 | 中 |
| 可修改 | 只能整片重跑 | 单镜头重生成；改文案 / 配音 / 配乐不重跑画面；一次输出多画幅 | **大** |
| AI 标识 | 成片没有“AI 生成”显式标识和元数据隐式标识 | 《人工智能生成合成内容标识办法》（2025-09-01 施行）要求显式 + 隐式标识 | **必须补** |
| 产品外壳 | Studio 是单页：一个输入框、一个任务 | 账号与团队、项目库、审片批注、批量队列、API、计费 | **大** |
| 模型授权 | 多数为 Apache-2.0；Nemotron 为 NVIDIA Open Model License | 逐个核实商用条款；**LTX-2.5 社区许可对年收入有门槛，需核实** | 需核实 |

## 二、画质：问题出在哪、怎么修

一支成片的像素经过四步，每一步都在丢清晰度：

| 步骤 | 现状 | 修复 | 状态 |
|---|---|---|---|
| 首帧 | Qwen-Image-Edit 出 704×1280 | 按成片尺寸生成（模型原生上限约 1.76 MP，超出部分用 lanczos 放大） | 随默认 1080p 生效 |
| 视频 | LTX 在 352×640 采样，潜空间放大到 704×1280 | 原生 1080p：在 544×960 采样，放大到 1088×1920 | **已实测**：一段 5 秒 4 分 07 秒（720p 约 2 分钟），1088×1920，清晰度明显提升 |
| 保存 | ComfyUI `SaveVideo` 默认参数，0.63 Mbps | 用 ComfyUI 动态参数 `format.codec.encoding.crf = 12` 近无损保存 | **已修**：实测 6.5 Mbps |
| 成片 | 704×1280 拉伸到 1080p 后 14 Mbps 编码 | 原生素材直接合成；H.264 High、crf 16；2K/4K 档位先用 lanczos 放大并在报告里标注，之后接入视频超分模型 | 进行中 |

**分辨率档位**（`src/lib/formats.ts`）：`1080p`（默认）、`2k`、`4k`、`6k`。生成分辨率上限为 1080p（模型能力和内存决定），交付分辨率按档位输出；高于 1080p 的档位在交付报告中写明“放大”，不冒充原生。

## 三、制作标准：按顶级广告片的流程来做

真实的顶级广告片流程是：**创意概念 → 导演阐述（treatment）→ 分镜与镜头表 → 美术与布光设计 → 拍摄 → 剪辑 → 调色 → 声音设计与混音 → 交付**。Cinefoundry 的 8 个阶段要一一对上，每一步都有可检查的标准。

### 1. 创意与导演阐述（脚本 + 分镜阶段）
- 每支片先定一个**视觉概念**：一句话说明“这支片看起来像什么”（例如“清晨厨房里的一束逆光，所有东西都慢下来”），之后每个镜头都服从它。
- 定**光线时间与光源逻辑**：日景 / 黄昏 / 夜景，主光从哪来（窗、台灯、顶光），整支片保持同一方向和色温，不能一个镜头暖、一个镜头冷。
- 定**色彩方案**：主色、辅色、点缀色各一个，和产品色呼应。

### 2. 镜头设计（分镜阶段）
- **节奏**：15 秒片的经典结构是“钩子（0–5 秒，第一秒就要抓住人）→ 证明 / 体验（5–10 秒）→ 产品高光（10–15 秒）→ 定版”。
- **景别递进**：相邻镜头景别必须拉开（特写 → 中景 → 全景，或反过来），不能连续两个同景别。
- **镜头语言用画面词，不用参数**：图像模型会把“50mm”“f/1.4”画成字，所以写“长焦压缩感的背景”“微距探针镜头的贴近视角”“极浅景深、奶油般的焦外”。
- **16:9 构图**：主体放在三分线上，标题所在的一侧留出负空间；地平线在三分线；用前景虚化做层次。
- **运镜**：一个镜头一个动作，速度写清楚（“极慢推近，5 秒内只推近十分之一”），起幅和落幅都要是好构图。

### 3. 布光与质感（分镜阶段，按品类）
- 饮料：逆光 + 侧逆光勾出液体和瓶身轮廓，冷凝水珠要有高光，背景暗或纯色。
- 护肤：大面积柔光、低反差、浅色背景，膏体纹理微距，皮肤保留真实纹理。
- 食品：暖色侧光、蒸汽逆光、食材质感特写。
- 数码：暗场、硬边轮廓光勾勒金属倒角，一到两种光色。
- 电脑与服务器：暖金色柔光，至多一点绿色点缀。
- 家居：实景光感（台灯、窗光为动机光源），温暖低照度。

### 4. 去 AI 感（画面）
禁止或拒收：塑料 / 蜡质皮肤、过度光滑的材质、过饱和、HDR 光晕、所有东西都在画面正中、无动机的彩光、几何扭曲、对称到不自然的构图。要求：真实材质的细微瑕疵、自然光衰、景深层次、轻微胶片颗粒。

### 5. 剪辑与调色（成片阶段）
- 镜头之间**默认硬切**，只在进入定版时用 0.5 秒溶解。
- 调色按品类出方案（饮料清透、护肤柔和、食品温暖、数码深黑中性、电脑暖金），整片统一调色；锐化克制，颗粒细。

### 6. 声音（成片阶段，与画面同等重要）
- **配音选角**：按品类和人群选声线，例如数码和汽车用沉稳的男中音，护肤用温润的女声，饮料用年轻明亮的声音，食品用亲和的声音。音色用 VoiceDesign 按具体描述设计（年龄、音高、共鸣、语气），不用真人录音。
- **播音腔**：电视广告的“说”而不是“念”——语速约每秒 4 字，句尾自然下沉，品牌名和核心词上重音，句间留气口。文案里用标点控制停顿。
- **音效**：环境声（室内、街道、厨房）+ 动作音效（开罐、倒水、冰块、按键、翻页）+ 关键转场的轻声效；与画面动作同步，音量服从配音。
- **配乐**：按情绪和节奏选，结尾落在定版上收住。
- **混音**：配音始终清晰；网络投放 -16 LUFS、电视 -24 LKFS，真峰值 -1 dBTP。
- **去 AI 感（声音）**：一支片一个声音；不用机械的匀速语调；文案避免书面腔和口号堆砌。

### 7. 文案去 AI 感（脚本阶段）
- 像人说话：短句、口语、具体的感受。
- 禁用 AI 套话：“开启……新篇章”“焕新”“赋能”“不止于……”“满满的……”“让……成为可能”、四字词堆砌、排比。
- 每句都能被一个真实的人对着镜头自然说出来。

### 8. 字幕与标题（成片阶段）
- 字幕一行，不超过 16 字，按配音实际时长逐句出现，放在下方安全区，不压产品。
- 标题是画面设计的一部分：字号层级、字距、位置与构图负空间对齐，淡入淡出。
- 字体用 Noto Sans / 思源黑体（商用可用），品牌可替换为自有字体。

### 9. 合规与 AI 标识
- 每支成片加**显式标识**：片头和定版位置显示“内容由 AI 生成”。
- 加**隐式标识**：文件元数据写入 AIGC 标识字段（生成方、内容编号）。
- 合规审核记录随交付包导出。

## 四、Skill 逐个复盘与改写要点

Harness 只把每个 Skill 的 `SKILL.md` 正文注入模型提示词（`src/agent/skills.ts`），`references/` 目录不会进入提示词。所以制作标准必须直接写进 `SKILL.md`。

| Skill | 现状 | 改写要点 |
|---|---|---|
| `ad-brief-intake` | 57 行；只提取产品、受众、信息、画幅 | 默认 16:9；补投放渠道（电视 / 网络 / 竖屏平台，决定画幅和响度）、品牌调性、配音性别偏好、参考风格 |
| `ad-script-writing` | 60 行；字数规则 + 品类禁忌 | 加 15 秒片节奏结构、电视广告文案写法、口语化与 AI 套话禁用表、每拍的配音语气标注（情绪、语速、重音词） |
| `ad-compliance-review` | 52 行 + rules.md | 加 AI 生成标识要求；品类规则包（食品、化妆品、数码、家居）；审核记录格式 |
| `storyboard-design` | 115 行；几乎全是避坑规则 | 重写为导演手册：视觉概念、光线逻辑、色彩方案、景别递进、16:9 构图与负空间、画面词替代参数、运镜速度与起落幅、品类布光方案、去 AI 感清单；保留现有避坑规则 |
| `shot-quality-gate` | 51 行；只拦错误 | 加审美评分维度：布光、构图、质感真实度、AI 感、清晰度，各 0–10 分，低于阈值重生成；没出结论时重试而不是判失败 |
| `spark-local-media-generation` | 74 行 + workflows.md | 写入分辨率档位、1080p 实测耗时与内存、近无损保存参数、各模型的适用场景 |
| `final-cut-assembly` | 38 行 | 重写为后期手册：硬切为主的剪辑规则、品类调色方案、标题与字幕排版规范、声音设计与混音标准、交付规格（码率、响度、AI 标识） |

| `ad-reference-breakdown` | 58 行；未接入主流程 | 保持可选；补“从参考片提炼导演语言”的输出项 |
| `cinefoundry-ad-film` | 75 行（入口） | 默认 16:9 / 1080p；交付时调用 `present` 让成片在对话里弹出 |
| **新增** `ad-voice-and-sound` | 无 | 配音选角、播音腔要求、文案停顿标记、音效清单与同步、配乐、混音和响度标准 |

## 五、执行顺序与验收标准

**第 1 步：管线与默认值（代码）**
默认 16:9 + 1080p；分辨率档位；近无损中间片段（已完成）；硬切为主的剪辑；品类调色方案；成片编码规格；AI 显式 + 隐式标识。

**第 2 步：Skill 重写**
按第四节逐个改写，并新增 `ad-voice-and-sound`；每个 Skill 的规则能被代码检查的，同时写进 `src/agent/checks.ts`。

**第 3 步：声音系统**
配音音色库（按品类设计）；播音风格；音效层（选用商用授权干净的音效来源）；字幕与配音逐句对齐；响度标准化。

**第 4 步：回归**
用同一组 4 个品类的创意，在 dsh-ad-demo 工作区以 16:9 / 1080p 重跑并录屏，逐项验收：

| 指标 | 目标 |
|---|---|
| 出片率 | 4/4 |
| 成片实际分辨率 | 原生 1088 或 1080 行，中间片段 ≥ 5 Mbps |
| 首帧一次通过率 | ≥ 60%，且审美平均分 ≥ 7 |
| 合规 | 违规卖点 100% 改写，成片零 block 级违规 |
| 声音 | 响度 -16 LUFS ±1，真峰值 ≤ -1 dBTP；字幕与配音逐句对齐 |
| AI 标识 | 显式和隐式标识都在 |

**之后**：单镜头重生成与局部修改、多画幅输出、品牌库、Studio 产品化（项目库、审片、批量队列、API、计费）。
